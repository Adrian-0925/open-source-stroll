关于开源散步

好工具，值得被发现。

我们用简短的中文，介绍开源项目的用途和使用门槛。感兴趣了，就去原仓库继续了解。

项目资料来自 GitHub 官方接口，后台每小时同步；每天按 America/Denver 日期自动筛选 6 个未推荐过的项目。第一期保留人工编写的中文介绍，新增项目简介自动翻译为中文，仓库原文保留在使用提示内。接口限流时保留上次成功的数据，顶部可查看同步时间。自动筛选不代表本站已安装测试每个项目。

项目头像取自 GitHub 仓库作者或组织，用于标识来源；右侧的图片示意由本站绘制，并非软件截图。

收藏只保存在当前浏览器，不会上传。清除站点数据会同时清除收藏。问题和建议可在 GitHub 仓库的 Issues 中反馈。
